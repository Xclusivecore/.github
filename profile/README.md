# Xclusive

- **X - Our Mark**  
  X is not merely a letter. It is the sign by which we are known.

- **C - Core**  
  The heart from which all else flows.

- **L - Loyalty**  
  Faithful to one another through all that comes.

- **U - Unity**  
  Each of us a part and all of us a whole.

- **S - Solidarity**  
  Steadfast in joy and steadfast in sorrow.

- **I - Integrity**  
  We shall remain true to who we are.

- **V - Vision**  
  A far horizon and a journey ever onward.

- **E - Evolution**  
  Never finished and always becoming.
